# Pixel Tart RC2 前台验收清单

请使用 RC2 安装版，在不使用真实客户资料的情况下逐项操作。只有用户亲自确认后，才可以把 `UserVerified` 改为 `true`。

## A. RAW 转 JPG

1. 选择一张测试用 ARW 文件。
2. 选择输出目录并开始转换。
3. 确认输出目录生成 JPG。
4. 查看转换窗口的最终状态。
5. 查看任务中心的最终状态。

验收重点：转换窗口和任务中心必须显示同一个结果，不能一个成功、一个失败。

## B. 批量压缩

1. 选择一张测试用普通 JPG。
2. 执行压缩并选择输出目录。
3. 确认输出成功。
4. 确认任务中心状态一致。

如果失败，点击“查看原因”，确认能看到明确原因。

## C. 日历拍摄流程

1. 创建测试排期，状态为“待拍摄”。确认日期为红色。
2. 执行“标记拍摄完成”。确认日期立即变为黄色，且不出现长期绿色状态。
3. 重启应用。确认日期仍为黄色。
4. 执行“标记已交付”。确认日期变为蓝色。

## D. 日历右键

在日期上点击右键，分别测试：

- 查看当天详情
- 创建拍摄
- 关闭档期
- 重新开放

确认每个项目都有真实响应。

## E. 关闭档期持久化

1. 关闭某一天的档期。
2. 退出应用并重新打开。
3. 确认该日期仍显示为关闭状态。

## F. 在线选片

1. 创建选片项目并打开项目。
2. 切换四个标签页。
3. 导入测试照片。
4. 查看是否生成代理 JPG。
5. 测试结果同步到归片。

如果没有配置真实云服务，显示“Provider None”属于正常现象。
